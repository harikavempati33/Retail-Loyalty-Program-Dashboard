📊 Retail Loyalty Program Performance Dashboard

This project is a Power BI dashboard that analyzes customer purchasing behavior and evaluates the performance of a retail loyalty program.

🔍 Key Insights
Loyalty members contribute a major portion of total sales
Seasonal trends affect purchasing behavior
Certain product categories generate higher revenue
Payment methods and customer demographics influence sales
📈 Dashboard Features
Total Sales & Customer KPIs
Loyalty vs Non-Loyalty Analysis
Category-wise Sales
Seasonal Sales Trends
Location-based Sales Map
Payment Method Distribution
Customer Gender Analysis
🛠 Tools Used
Power BI
Dataset from Kaggle
